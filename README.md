## 👉 Deskripsi
Aplikasi Konversi Suhu adalah konversi suhu ini berbasis aplikasi Microsoft visual studio yang dibuat untuk membantu pengguna memoermudah konversi suhu dan efisiensi waktu.

Proyek ini dibuat dengan fokus pada clean code, desain minimalis, dan user experience yang nyaman.
